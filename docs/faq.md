LSNC FAQ
Frequently asked questions about the LibreShare Non-Commercial License (LSNC).

What is the LSNC?
The LSNC is an open-source license that allows non-commercial use, modification, and sharing of software, with a copyleft requirement to share source code. It prohibits commercial use and reverse engineering of compiled versions.

Can I use the LSNC for my project?
Yes! The LSNC is designed to be used by anyone. Simply include the license file or a link to it in your project and comply with its terms.

Can I use LSNC software in a school or university?
Yes, the LSNC explicitly allows non-commercial educational use, such as in schools, universities, or training programs, as long as it remains non-commercial.

Can I use LSNC software for commercial purposes?
No, commercial use is prohibited unless you obtain written permission from the Rights Holder (lameur.tech@gmail.com).

What is copyleft?
Copyleft means that any derivative work based on LSNC-licensed software must be distributed under the same license (LSNC) and include the source code.

Can I combine LSNC software with software under another license?
Combining LSNC software with software under a different license requires prior agreement from the Rights Holder. Contact lameur.tech@gmail.com for details.

How do I contribute to the LSNC?
We welcome suggestions to improve the LSNC! Open an issue or submit a pull request on GitHub.

Where can I get help?
Contact the Rights Holder at lameur.tech@gmail.com or via github.com/Lameur for any questions or requests.
